Расстановка мебели

Выберите карточку → наведите на пол → клик для установки. Левая кнопка на мебели — двигать. Alt + левая — вращать камеру, правая — сдвигать, колесо — приближать. R — поворот предмета, Delete — удалить. Магнит притягивает близкие грани; Ctrl временно отключает его.

Каталог · габариты X × Z × высота

Выберите предмет для изменения размеров.

Сохранение расстановки

Перед закрытием сохраните JSON. Изменения не сохраняются автоматически. Пересечения подсвечиваются, но не запрещаются. Габариты локальные: поворот меняет их ориентацию на плане.

Выберите первую точку.

Два клика левой кнопкой — концы отрезка. Третий клик начинает новый замер. Длина считается в плоскости пола (X/Z), без высоты.

Без галочки — луч до плоскости пола, сквозь мебель. С галочкой — ближайшая непрозрачная поверхность. Обзор — перетаскивание мышью; WASD — перемещение.

2D-план · размеры в метрах

Приблизительная реконструкция, не обмерный чертёж. Длины — по осям участков модели, между их заданными концами; не чистые размеры комнат. Окна и ограждения перечислены отдельно. Числа округлены до 0,001 м для проверки модели, а не как оценка точности.
