# Кухня из отдельных модулей

Старая кухня (два составных объекта kitchen и counter со шкафами, столешницами, встроенными мойкой и варочной панелью) убрана из исходной расстановки. Обеденный стол, стулья, стены и остальные комнаты сохранены. Типы kitchen/counter остаются поддержанными для совместимости: импорт старого JSON восстанавливает его содержимое, включая старую кухню. При необходимости выберите эти предметы и удалите кнопкой «Удалить».

В каталоге 27 кухонных модулей и приборов. Два ранее добавленных холодильника находятся в разделе «Кухня · техника». Все размеры — стартовые условные габариты для планирования, не монтажные спецификации производителя. Отдельные столешницы из каталога убраны: нижние тумбы, модули с ящиками и тумба под духовку уже имеют верхнюю поверхность.

| Раздел | Варианты |
| --- | --- |
| Нижние модули | Тумбы шириной 30/40/45/60/80/100 см, ящики 40/60/80 см, открытая тумба под духовку 60 см, мойка с тумбой 60/80 см; все со столешницей |
| Верхние и пеналы | Верхние шкафы 40/60/80 см, высокий верхний 60 см, пеналы 40/60 см |
| Техника | Варочные панели на 2/4 зоны, духовка, настольная/встраиваемая микроволновка, посудомойки 45/60 см, вытяжки 60/90 см, два холодильника |

## Сборка

1. Добавьте нижние модули. Их общая высота со столешницей — 90 см. Фасад направлен по локальной оси +Z. Поворот меняет его направление.
2. Совмещайте соседние модули торцами; верхние поверхности окажутся на одной высоте. Модуль мойки уже имеет свою поверхность и смеситель.
3. Варочная панель и настольная микроволновка добавляются низом на высоте 90 см. Верхние шкафы — на 150 см, вытяжки — на 165 см. Это лишь стартовые значения.
4. Поле «От пола до низа, м» задаёт высоту установки любого предмета. «Высота корпуса» — его собственный размер, а не положение над полом. JSON хранит их отдельно: y и h. Старые предметы без y стоят на полу.
5. При перемещении мышью высота установки сохраняется. Привязка к поверхностям не автоматическая: после изменения высоты нижних модулей вручную скорректируйте высоту техники. Пересечения проверяются с учётом высоты; соприкасающиеся поверхности не считаются пересечением. Для техники внутри открытой тумбы возможно предупреждение из-за прямоугольных габаритов — оно не запрещает размещение.

Файлы JSON, сохранённые до этого изменения, поддерживаются. Если в старой расстановке были отдельные столешницы, они останутся при импорте и могут наложиться на новые поверхности нижних модулей. Такие предметы можно выбрать и удалить вручную.

Глубины, технологические зазоры, вырезы, вентиляция и расстояние до вытяжки должны уточняться по конкретной технике перед реальным монтажом. Модель для экспериментов, не рабочий проект кухни.

Перед обновлением страницы сохраняйте свою расстановку в JSON. Файлы не публикуются.
